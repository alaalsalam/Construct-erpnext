# مسودة مصفوفة الأدوار والصلاحيات

## الملخص

هذه المسودة تحدد الأدوار المقترحة لاختبار العميل قبل ضبط صلاحيات الإنتاج النهائية. لا يتم تطبيق قيود صارمة جديدة قبل اختبار السيناريوهات مع العميل وفريق الإدارة.

## الأدوار المقترحة

| الدور | نطاق العمل | شاشات رئيسية |
|---|---|---|
| Executive | متابعة المؤشرات والتقارير العليا | Executive Presentation Center، Executive Control Center |
| CFO | التقارير المالية، التدفق النقدي، المستخلصات، التحصيل | CFO Analytics، Contractor Management، Sales & Rental |
| Project Manager | متابعة المشروع من BOQ إلى IPC | Construction Control، Procurement، Measurement & IPC |
| Site Engineer | القياسات والموقع والملاحظات التشغيلية | Measurement Book، Measurement Entry، Maintenance |
| QS Engineer | الكميات، الفروقات، المستخلصات | BOQ، Work Items، IPC، Project Purchase Control Summary |
| Procurement Officer | طلبات المواد والمشتريات والمخازن | Procurement & Site Warehouses |
| Finance Officer | الفواتير، السداد، التقارير المالية | Sales Invoice، Payment Entry، Contractor Ledger |
| Sales Officer | الحجوزات، عقود البيع، التحصيل | Unit Reservation، Sales Contract، Buyer Statement |
| Leasing Officer | عقود الإيجار وجداول الإيجار والتحصيل | Lease Contract، Rent Schedule، Tenant Statement |
| Property Manager | الوحدات، الصيانة، المستندات، الملاك | Real Estate Inventory، Maintenance، Property Documents |
| Contractor Portal User | نطاق مستقبلي للمقاول | Portal Readiness فقط حالياً |

## ملاحظات مهمة

- لا يتم تفعيل صلاحيات بوابة عامة حالياً.
- لا يتم تضييق الصلاحيات قبل UAT حتى لا يتعطل العرض.
- صلاحيات الإنتاج النهائية تحتاج اعتماد الإدارة والمالية.
- أي صلاحية على المستندات المحاسبية يجب اختبارها مع ERPNext القياسي.
